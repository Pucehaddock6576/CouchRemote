# Feature guide

Couch Remote has several features. Each can be configured from its corresponding Settings panel or button mapping.

## Touch modes

- **Trackpad:** the Siri Remote’s glass surface moves the Mac pointer. Click and gesture behavior can be adjusted.
- **Remote:** swipes, tap zones, and surface-edge clicks become directional navigation/select actions. Music swipes can skip tracks while supported music playback is active.
- **Scroll:** use touch movement to scroll pages.

The Siri Remote does not replace a full keyboard or conventional mouse in every application. Use the app’s touch and button settings to tune behavior.

## Buttons and profiles

Map physical buttons and touch gestures to built-in media, mouse, mode, app, window, desktop, power, and Couch Remote actions. Some actions can send a keystroke, type text, open a URL, run user-defined AppleScript, or run a shell command. See [Buttons and touch modes](Buttons-and-Touch-Modes.md).

App Profiles let mappings and touch mode change for selected frontmost apps. A Global profile is used as the default/fallback.

## Big Screen

A full-screen, remote-first home interface contains browsable rows, widgets, music/TV/library/search pages, a Now Playing card, and configurable watch shortcuts. It is intended to be usable by swiping/clicking the remote without reaching for a keyboard. See [Big Screen](Big-Screen.md).

## Couch Menu and keyboard

The Couch Menu is a compact remote-controlled launcher/menu. The on-screen keyboard lets the remote enter text, with optional physical button mapping while it is open.

## Media and web video

Couch Remote can control playback in supported players, display Now Playing information when macOS shares it, and use browser scripting for selected web-video actions. MediaRemote and some browser behavior depend on macOS/app versions and permissions.

## Built-in YouTube

The app has a WebKit window configured for a TV-style YouTube experience. The URL and TV-user-agent setting can be changed in Big Screen settings. YouTube can change its web interface or block a client at any time.

## Phone remote

An optional HTTP page served by the Mac allows a phone on the same local network to send pointer, click, keyboard, media, and Big Screen commands. It requires no phone app. It has no authentication or HTTPS; see [Phone remote](Phone-Remote.md) before enabling it.

## Additional utilities

Depending on settings and mappings, the app also includes a sleep timer, Mousespot/laser pointer, draw-on-screen, presenter overlay, HUD popups, battery and calendar/weather widgets, and remote keep-awake checks. Availability depends on Mac hardware, macOS permissions, and connected services.
