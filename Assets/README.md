# Visual assets

- `Brand/CouchRemote.icns` — the app bundle icon included by `build.sh`.
- `Brand/couch-remote-icon.svg` — editable square icon master.
- `Brand/couch-remote-mark.svg` — symbol-only mark on transparent background.
- `Brand/couch-remote-lockup.svg` — editable banner source; the PNG is used at the top of the root README.
- `Brand/Visual-Philosophy.md` — short concept note behind the original identity.
- `Diagrams/*.svg` — editable source diagrams. Matching PNGs are supplied for Markdown renderers without reliable inline SVG support.
- `../Screenshots/overview-redacted.png` — cropped app screenshot with the unique remote identifier removed.

SVGs are the editable masters; PNGs are rendered previews. The icon is an original abstract design evoking a tactile surface and a response moving outward. It is not an Apple logo or a reproduction of Apple's app icon.
