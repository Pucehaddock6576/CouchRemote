# Community Code of Conduct

We want Couch Remote discussions and contributions to be welcoming, respectful, and constructive for everyone.

## Expected behavior

- Be considerate and respectful; critique ideas and code, not people.
- Explain disagreements calmly and assume good faith where reasonable.
- Share technical information responsibly. Do not post another person’s private data, credentials, personal configuration, or security exploit details publicly.
- Keep discussion focused on the project and help make participation accessible to newcomers.

## Unacceptable behavior

Harassment, threats, discriminatory language, personal attacks, doxxing, deliberate intimidation, and sustained disruptive conduct are not acceptable.

## Reporting and enforcement

If you experience or witness unacceptable behavior, contact the repository maintainer privately using the contact channel published on the GitHub repository. Do not include sensitive details in a public issue. Maintainers may edit or remove content, close discussions, or restrict participation when needed to keep the project safe and constructive.

This project has not yet specified a dedicated enforcement team or response-time commitment. The repository owner should add an appropriate private contact method before broad public launch.
